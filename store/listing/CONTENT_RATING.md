# Content rating questionnaire (IARC): answers for Angadi

Play Console → **Policy → App content → Content rating → Start questionnaire**.

1. **Email address:** the developer's support email (the same one as in the privacy policy).
2. **Category:** **All other app types** (the utility / productivity / business category; not a game, not social, not news).
3. Answers:

| Question (short form) | Answer | Why |
|---|---|---|
| Violence, blood or gore | **No** | Billing screens only. |
| Fear / horror content | **No** | |
| Sexuality or nudity | **No** | |
| Offensive or crude language | **No** | Item names are typed by the shop owner; the app ships only a grocery item list. |
| Controlled substances (drugs, alcohol, tobacco) referenced or promoted | **No** | The app does not depict or promote them. A shop may bill such items, but that is its own stock list, not app content. |
| Gambling or simulated gambling | **No** | |
| Users can interact or exchange content with other users in the app | **No** | No chat, no accounts, no feed. Sharing a receipt hands a PDF to WhatsApp outside the app. |
| App shares the user's current physical location with other users | **No** | No location permission. |
| Users can buy digital goods in the app | **Yes** | The Angadi Pro subscription via Google Play Billing. |
| Unrestricted internet access (web browser, search engine) | **No** | |
| Is it a web browser or search engine | **No** | |

4. **Save → Submit.** Expected result: the lowest age band in every region (e.g. *Everyone* / *PEGI 3* / *3+*), with the
   *In-App Purchases* notice. If a region shows anything higher, an answer above was entered wrong.
